**Stack:** Python, OpenCV, Ultralytics YOLO26, scikit-learn, BM25/TF-IDF, NetworkX, Pandas

**Stack:** Python, Pandas, DuckDB, scikit-learn, FastAPI, Streamlit, Pytest, GitHub Actions
